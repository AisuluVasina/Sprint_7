# Спринт №7 Тестирование API
Проект содержит автотесты для  Яндекс Самокат

# В автотетстах используется:
Selenium WebDriver

# Структура проекта

- api_client.py — реализация API клиента
- conftest.py — фикстуры для управления данными

# Список тестов
- test_courier_create.py - Создание курьера
- test_login_courier.py - Логин курьера
- test_create_order.py - Создание заказа
